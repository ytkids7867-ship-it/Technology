# TechPulse website

Responsive static technology publication starter. Includes article search and filters, categories, individual article pages, dark mode, responsive navigation, About, Contact, Privacy, Disclaimer, robots.txt and sitemap.xml.

## GitHub Pages setup
1. Create a public GitHub repository.
2. Upload every file and the `assets` folder, keeping the folder structure.
3. Repository Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Replace `https://example.com/` in index.html, robots.txt and sitemap.xml with your real site URL.
5. Update the privacy policy and contact details.

## Before launch
The included articles are starter evergreen content, not live breaking news. Research and publish original, fact-checked updates. Contact and newsletter forms are demos and need a form/email provider. No advertising code is included. Do not copy other publishers' text or images.
